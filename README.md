# Side Quests

This KMP project is meant to be a collection of apps that I use. 

## Riso

A custom theme, inspired by risograph printing. The theme provides a paper-like surface, and ink 
drums. Each ink pass has an alignment "error", which is amplified for effect in this case.
That's why the colors are not aligned in the example below.

## Sumar

A Bucharest-metro-themed audio guide, matching the "SUMAR" Figma design. Title screen, a
metro-map player screen, and a credits screen — scaffolded so far for Android and iOS; the real
audio playback and the map artwork itself still need to land.
